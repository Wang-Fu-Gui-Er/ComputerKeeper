# 这是一个基于Python PyQt5 开发的摸鱼工具

企业微信、钉钉、飞书等办公软件一直会检测电脑在线状态，电脑无操作后会直接显示离开状态，这就让我们很不安心的摸鱼了，于是需要一个工具来保证电脑一直被激活。

# 功能

设定一个时间段，让电脑一直保持被唤醒

# 前置工作

`pip install PyQt5`

`pip install pyinstaller`

# 落地

`pyinstaller -F -w --icon=icon.ico --add-data "icon.png;." .\ComputerKeeper.py`
